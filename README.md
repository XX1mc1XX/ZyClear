智澈 ZyClear｜跨品牌工业相机客户端(独立开发)
架构设计、硬件抽象层、参数体系、图像链路、构建与界面工程化全线负责

- **技术栈**：C++17 / Qt 6（Widgets · Concurrent · Model-View-Delegate · QDockWidget）/ OpenCV 4.x / 海康 MVS SDK（MvCameraControl）/ CMake / MSVC / Windows · Linux

- **定位**：不止是相机上位机，更是**可复用的工业客户端底座**——设备维度换品牌只改 1 处注册、加型号改 0 行 C++，可平移至 PLC、运动控制卡等工业设备客户端；应用维度可把插件层与 AI 层整包搬到别的客户端
- **简介**：面向工业视觉产线，覆盖**设备发现、接入、调参、配置持久化、实时成像、多机切换**全生命周期。工业现场多品牌 SDK 接口异构，传统写法每接一个品牌都要改遍上层；本项目以架构手段把厂商差异关进实现层（占 **12.2%** 代码量），其余 **87.8%** 的代码对品牌完全无感，可平移至 PLC、运动控制卡等工业设备客户端。
#### 核心职责与成果
### 一、架构设计与复用（核心护城河）
  1. **六层单向依赖架构**：契约层、实现层、门面层、模型层、交互层、资源层逐层隔离，依赖倒置、单向向下，变化点向内收敛。三条核心约束**可用 grep 当场验证**——门面层不出现任何适配器头文件、面板之间零相互引用、交互层零厂商判断；全仓厂商条件编译仅 **2 处**，且都落在工厂的注册与枚举。
  2. **契约先行与硬件无关的能力边界**：**17 个纯虚方法**覆盖设备全生命周期、参数读写、图像获取三域；统一门面以「**序列号 → 设备对象**」映射收口多机寻址与对象生命周期托管，交互层全程只凭序列号寻址、不感知品牌。新品牌接入由**侵入式改造**降级为**增量式扩展**，改动面收敛 **95%**，门面、参数面板、图像链路零改动。
  3. **设计模式体系化治理变化点**：创建解耦（工厂按厂商名登记创建器与枚举器）、入口收敛（门面）、异构适配（适配器把厂商 SDK 差异封在实现层）、事件分发（发布-订阅总线）、对象复制（参数原型克隆）、数据视图分离（Model-View-Delegate）、树形组合（参数分组树）、全局资源治理（单例托管注册表与门面）、高吞吐削峰（有界双队列），选型以**变化点隔离**为唯一判据。
  4. **参数能力由代码资产转为配置资产**：将参数定义建模为「**6 种参数类型 × 5 个业务分组 × 37 项 Schema**」，配置解析与界面渲染彻底隔离，视图**运行时动态装配**；新增型号**不编译、不发版**，改 JSON 分钟级生效，上线效率提升 **80%**。
  5. **参数权限闭环自动推导**：打通 GenICam 访问模式（RO / RW / WO / NI / NA）到界面语义的映射链，参数的**有效性、可读性、可写性三态**由设备实时上报、逐项自动判定；只读项在**模型层**即被拦下（视图连编辑控件都不会创建），不支持项静默剔除，**参数界面不含任何硬编码权限判断**。
### 二、图像链路与性能优化
  6. **像素格式归一化**：覆盖 **36 种** GigE Vision 像素格式（Mono / Bayer / YUV / BGR 各族）判定，借 SDK **硬件转换通道**统一归约为**灰度与彩色两种形态**，上层图像链路与像素格式彻底解耦，且转换失败不产出半成品帧。
  7. **高吞吐图像缓冲层**：空闲 / 工作**双队列**复用 + **保新弃旧**（满队列丢弃最旧帧并回收其缓冲，保障预览实时性），取帧带**超时保护**、归还闭环回收、稳态零堆分配；采集回调、有界缓冲队列、独立采集线程、界面渲染**四级异步隔离**，持续满帧下界面不阻塞、无延迟堆积。
  8. **发布-订阅总线消除面板网状耦合**：跨面板联动收敛为 **6 类语义事件**按位掩码定向投递，模块间**零直接引用**，新增面板与事件类型不触动既有业务；配套 **15 类错误码 + 成功码**的统一错误模型，异常收口至**状态栏 + 模态**两级触达。
### 三、工程化与效能提升（研发侧赋能）
  9. **界面即代码替代可视化拖拽**：全仓**零二进制窗体**，布局骨架、弹性策略、主题钩子**全量代码显式声明**，消除生成代码不可读、不可评审、不可合并三个问题；参数区仅保留空壳视图，**6 类编辑控件**按类型运行时挂载，界面层对参数规模**完全无感**。
  10. **状态驱动的交互互锁**：拉流期间参数面板**自动整面禁用**，断连、重枚举与切换相机**自动清空脏帧与旧参数**；交互可用性由设备状态事件**单向推导**，非法操作序列在架构层被排除，而非依赖人工纪律。
  11. **设备独占与幂等重入**：连接前判定设备**独占占用**、异常接入**显式降级为可读错误**；重复枚举**自动停流、断连、逐台重建注册表**，句柄与设备占用无残留；设备信息**值拷贝自持**，不引用 SDK 枚举列表内部内存；SDK 运行日志**定向落盘**，现场故障可回溯。
  12. **虚拟设备抽象（同构仿真）**：与真机共用同一套契约与同一个图像缓冲队列，开发、调试、演示、压测、持续集成**全程无需真机**，硬件采购成本归零；仿真的全链路替代使硬件依赖降级为可选项。
  13. **声明式构建与依赖管理**：源码清单、依赖声明、资源打包、交付路径**全部代码化**，元对象与资源编译**全自动托管**；**3 个项目自定义缓存变量**覆盖全环境差异，**官方包优先 + 手动兜底**双路径依赖探测，调试/发布构件自动二选一，产物集中落盘、整体可搬运，部署成本下降 **90%**。
  14. **多环境自适应兼容矩阵**：OpenCV 多部署形态、硬件 SDK 缺失**降级为纯仿真仍可构建可运行**、操作系统差异**三维覆盖**，交付物**单一、可复现、可搬运**；CI 即在**缺失厂商 SDK 的降级配置**下构建并跑通全部测试。
  15. **运行时装插件平台**：面板契约与注册表分离，主程序启动时扫描目录、以 **QLibrary 装载动态库**挂载面板，新增面板**不重编主程序**；插件接口只导出**纯 C 符号**（extern "C"），规避 C++ 类无稳定二进制布局导致的 ABI 断裂；**QDockWidget 停靠体系**支持任意边停靠、浮动成窗、关闭后从「视图」菜单恢复，工具栏按钮随面板实际停靠位置自动重排；注册表按唯一 ID 去重、同名注册被拒，附**独立示例插件工程**。
### 四、AI Agent 集成与质量保障
  16. **AI Agent 宿主：设备能力自动工具化**：接入 agent4cpp，把相机全生命周期能力注册为 **10 个 LLM 可调用工具**（枚举 / 连接 / 读写参数 / 拉流 / 画面量化分析），工具带用途描述与参数 Schema，自然语言即可驱动；工具提供者以**四方法接口**抽象，**通用 AI 层不含任何相机知识**，领域绑定收口在唯一的宿主适配层，Extension 目录**整包可移植**到其他客户端；同一 agent 核心另供**无头控制台模式**，命令行复用全套工具与会话历史；AI 依赖缺失时构建**自动降级**、主功能不受影响。
  17. **面向 LLM 可靠性的工程处理**：参数写入前用设备上报的 min/max 与枚举可选值校验，**超范围拒绝而非静默钳位**（钳位会让模型以为写进去的就是它要的值，后续推理全建立在错前提上）；写后**回读确认**并把「请求值 / 实际生效值」并列回传；工具失败以「可重试」语义回灌给模型自纠，步数上限兜底防调用不收敛；工具回调线程经阻塞队列调用切回主线程串行操作设备，避免给相机加锁。配套本地文档导入 → 切块 → **top-k 检索**灌注，多轮会话历史 JSON 落盘。
  18. **单元测试守住无硬件可测面**：图像缓冲队列（双队列复用 / 保新弃旧 / 超时归还 / 稳态零分配）、参数模型（类型判定 / 权限三态 / 整包写回）、JSON Schema 解析、事件总线、相机工厂与门面共 **8 个测试目标 114 个用例**，**刻意只选不含硬件依赖的纯逻辑组件**，无需相机与海康 SDK 即可编译运行；注册进 CTest 并与主程序共用运行时目录，**虚拟设备 + 单元测试构成不依赖真机的双层保障**。
