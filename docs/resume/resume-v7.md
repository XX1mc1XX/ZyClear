# 智澈 ZyClear ｜ 跨品牌工业相机客户端软件

**角色**：独立开发——架构设计、硬件抽象层、参数体系、图像链路、构建与界面工程化全栈负责

**定位**：不止相机上位机，更是**可复用的工业设备客户端架构范式**——**换品牌改 1 处注册，加型号改 0 行 C++，联调不占真机工时**。

**技术栈**：C++17 / Qt 6（Widgets · Concurrent · Model-View-Delegate）/ OpenCV 4.x / 海康 MVS SDK（MvCameraControl）/ CMake / MSVC / Windows

**规模**：约 **5000** 行**核心**代码 C++ / **27** 个编译单元 / **58** 个源文件 / **10** 个模块，GitHub 开源

**简介**：面向工业视觉产线，覆盖**设备发现、接入、调参、配置持久化、实时成像、多机切换**全生命周期。工业现场多品牌 SDK 接口异构，传统写法每接一个品牌都要改遍上层；本项目以架构手段把厂商差异关进 **16.4%** 的实现层，**83.6%** 的代码对品牌完全无感，并可平移至 PLC、运动控制卡等工业设备客户端。

## 核心职责与成果

1. **六层单向依赖架构**：契约层、实现层、门面层、模型层、交互层、资源层**逐层隔离**，依赖倒置、单向向下，**变化点向内收敛**；表现层**厂商条件分支清零**，跨模块**零直接引用**。

2. **契约先行**界定硬件无关能力边界：**17 个纯虚方法**覆盖设备全生命周期、参数读写、图像获取三域；统一门面以「序列号 → 设备对象」映射收口多机寻址与生命周期托管，上层仅凭**序列号寻址**、不感知品牌；新品牌接入由**侵入式改造**降级为**增量式扩展**，改动面收敛 **95%**。

3. **10 种设计模式**体系化治理变化点：**创建解耦、入口收敛、异构适配、事件分发、算法可替换、流程固化、对象复制、全局资源治理、数据视图分离、高吞吐削峰**各归其位，选型以**变化点隔离**为唯一判据。

4. **参数能力由代码资产转为配置资产**：**6 种参数类型 × 5 个业务分组 × 37 项 Schema** 建模，配置解析与界面渲染分离，视图**运行时动态装配**；新增型号**不编译、不发版**，上线效率提升 **80%**。

5. **参数权限闭环自动推导**：打通 GenICam 访问模式（RO / RW / WO / NI / NA）到界面语义的映射链，参数的**有效性、可读性、可写性三态**由设备实时上报、逐项自动判定；只读项在模型层即禁止编辑，不支持项静默剔除，参数界面不含任何**硬编码权限判断**。

6. **像素格式归一化**：覆盖 **30+ 种 GigE Vision 像素格式**（Mono / Bayer / YUV / BGR 各族）判定，借 SDK **硬件转换通道**统一归约为**灰度与彩色两种形态**，上层图像链路与像素格式解耦。

7. **高吞吐图像缓冲层**：空闲/工作**双队列复用 + 保新弃旧**，满队列丢弃最旧帧以保障预览实时性，取帧带**超时保护**、归还闭环回收；采集回调、缓冲队列、独立采集线程、界面渲染**四级异步隔离**，持续满帧下界面不阻塞、无延迟累积。

8. **发布-订阅总线**消除面板网状耦合：交叉联动收敛为 **6 类语义事件**按位掩码定向投递，模块间**零直接引用**，新增面板与事件类型不触动既有业务；配套 **16 类错误码**统一错误模型，异常收口至**状态栏 + 模态两级触达**。

9. **界面即代码**替代可视化拖拽：全仓**零二进制窗体**，布局骨架、弹性策略、主题钩子**全量代码显式声明**，消除生成代码不可读、不可评审、不可合并三个问题；参数区仅保留空壳视图，**6 类编辑控件**按类型运行时挂载，界面层对参数规模**完全无感**。

10. **状态驱动的交互互锁**：拉流期间参数面板**自动整面禁用**，断连与切换相机**自动清空重载**，交互可用性由设备状态事件**单向推导**，非法操作序列在架构层被排除而非靠人工纪律。

11. **设备独占与幂等重入**：连接前判定设备独占占用、异常接入**显式降级为可读错误**；重复枚举**自动停流、断连、重建注册表**，句柄与设备占用无残留；SDK 运行日志**定向落盘**，现场故障可回溯。

12. **虚拟设备抽象**：同契约仿真实现全链路替代，开发、调试、演示、压测、持续集成**全程无需真机**，**硬件采购成本归零**。

13. **声明式构建**：源码清单、依赖声明、资源打包、交付路径**全部代码化**，元对象与资源编译**全自动托管**；**3 个缓存变量**覆盖全环境差异，**官方包优先 + 手动兜底**双路径依赖探测，调试/发布构件自动二选一，产物集中落盘、整体可搬运，部署成本下降 **90%**。

14. **多环境自适应兼容矩阵**：OpenCV 多部署形态、硬件 SDK 缺失**降级仿真仍可继续构建**、操作系统差异**三维覆盖**，交付物**单一、可复现、可搬运**。
