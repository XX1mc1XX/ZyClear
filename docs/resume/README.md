## v7 相对 v6 的主要变化

- 补入四项能力：参数权限闭环自动推导、像素格式归一化、状态驱动交互互锁、设备独占与幂等重入
- 统一量化口径，去掉无法核验的表述
- 加粗收敛为两层结构：条目锚点 + 可核验的数据点
