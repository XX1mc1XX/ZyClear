## 完整版

### 智澈（ZyClear）—— 跨品牌兼容的工业相机客户端软件

**独立开发** ｜ C++17 / Qt6 / OpenCV 4.5 / 海康 MVS SDK ｜ 2023.xx - 至今

**项目概述：**
面向工业视觉现场，独立设计并开发了一款对标海康 MVS 的工业相机客户端软件。软件以海康工业相机 SDK 二次开发为基础，通过抽象相机接口层实现设备无关的架构设计，既支持海康全系列相机，也可零改动接入其他品牌相机。覆盖相机枚举、连接、实时采图显示、参数读写、配置文件导入导出等完整功能链路，具备企业级的可扩展性与可维护性。

**核心技术与要点：**

- **相机抽象层与工厂模式解耦**：设计 `CameraInterface` 抽象接口定义相机操作契约（连接/采图/参数读写），上层业务 `CameraContext` 仅依赖抽象而非具体实现，遵循依赖倒置原则；通过 `CameraFactory` 单例工厂 + 模板注册机制，新增相机品牌只需继承接口并注册，实现"零修改、纯新增"的开闭原则落地。

- **跨品牌相机兼容设计**：将海康 `MvCameraControl` SDK 封装为适配器实现，向上暴露统一接口，向下屏蔽 SDK 差异；虚拟相机 `VirtualCamera` 作为独立实现，支持脱离硬件开发调试，与真机实现共用同一套抽象契约，一套 UI 逻辑同时驱动真机与虚拟设备。

- **多线程图像采集与生产者-消费者队列**：自实现线程安全图像队列 `CameraImageQueue`，采用双队列（空闲队列 + 工作队列）+ `std::mutex` + `std::condition_variable` 设计，避免图像内存频繁分配；SDK 回调线程作为生产者入队，独立采集线程 `AcquireImageProcess` 作为消费者出队，主界面永不阻塞，实测稳定 60fps 无卡顿显示。

- **MVD 参数面板与类型驱动控件**：基于 Qt Model-View-Delegate 架构构建相机参数面板，`CameraParamModel` 承载树形参数数据，`CameraParamDelegate` 负责渲染与编辑；针对 int/double/bool/enum/string/cmd 六种参数类型，派生出 `OneCustomWidget` 系列自定义控件，实现"一个模型、多种编辑策略"的策略模式；参数按 group 分组树形展示，附带描述提示。

- **统一参数数据模型**：抽象 `CameraParam` 组合式数据结构，以 `QVariant` 统一承载六种参数类型，附带元信息（分组/名称/类型/取值域/提示）与访问权限位（valid/readable/writeable），屏蔽不同相机 SDK 的参数表示差异，实现参数层与 UI 层、SDK 层的三方解耦。

- **观察者模式事件总线**：自实现 `ListenerManager` 中央事件总线，控制面板、参数面板、视觉窗口三大模块通过注册监听实现状态联动（如连接成功→参数面板加载、开始采图→参数面板禁用），模块间无直接依赖，新增界面模块只需继承 `Listener` 即可接入。

- **JSON 驱动界面生成**：设计 `ParseUiJson` 单例解析器，以 JSON 描述相机参数元信息，运行时反序列化动态构建参数模型，新增相机型号仅需编写 JSON 文件、无需重新编译，实现"数据驱动 UI"。

- **图像显示与交互**：基于 `QGraphicsView` 框架构建视觉渲染窗口，封装 `ImageItem` 实现图像自适应缩放、鼠标滚轮缩放、拖动平移、双击居中、实时像素取色等专业交互，支持图像格式转换与 OpenCV 数据处理链路打通。

- **界面美化与工程化**：重构全部界面为深色主题（VS Code 风格），统一 `QPalette` 调色板 + QSS 样式表（760 行）双管齐下；采用 CMake 构建，配置 AUTOMOC/AUTORCC，兼容 Debug/Release 双配置链接，MSVC 强制 UTF-8 解决中文乱码，多平台构建（Windows/Linux）。

**项目成果：**

- 独立完成涵盖相机抽象层、工厂、事件总线、参数面板、图像队列在内的完整客户端软件，代码模块化分层清晰（表现层/业务层/抽象层/实现层/驱动层五层架构）。
- 架构侧实现"新增相机品牌零修改、新增相机型号零代码、新增参数类型纯新增"的高扩展性，达到企业级软件的可维护性标准。
- 虚拟相机机制支持无硬件开发调试，显著降低开发与测试门槛。
- 软件已开源，作为个人 C++/Qt 工业软件方向的代表作。

## 精简版

### 智澈（ZyClear）—— 跨品牌兼容工业相机客户端软件 ｜ 独立开发
**C++17 / Qt6 / OpenCV / 海康 MVS SDK**

- 独立开发对标海康 MVS 的工业相机客户端，覆盖枚举、连接、实时采图、参数读写、配置导入导出的完整功能链路，已开源。
- 设计 `CameraInterface` 抽象层 + `CameraFactory` 单例工厂，上层业务依赖抽象而非实现，新增相机品牌"零修改、纯新增"，落地开闭原则与依赖倒置。
