# 智澈 ZyClear ｜ 跨品牌工业相机客户端软件

**定位**：不止相机上位机，更是**可复用的工业设备客户端架构范式**——**换品牌改 1 处，加型号改 0 行，硬件投入归零**。

**技术栈**：C++17 / Qt 6（Widgets · Concurrent · Model-View-Delegate）/ OpenCV 4.x / 海康 MVS SDK / CMake / MSVC / Windows

**简介**：面向工业视觉产线，覆盖**设备发现、接入、调参、配置持久化、实时成像、多机切换**全生命周期。工业现场多品牌 SDK 接口异构，传统写法每接一个品牌都要改遍上层；本项目以架构手段把厂商差异关进 **16.4%** 的实现层，**83.6%** 的代码对品牌完全无感，并可平移至 PLC、运动控制卡等工业设备客户端。

## 核心职责与成果

1. 主导**六层单向依赖架构**（**约 5000 行核心代码** C++ / **58 文件** / **10 模块**）：契约层、实现层、门面层、模型层、交互层、资源层逐层隔离，**依赖倒置 + 单向向下**，**变化点向内收敛**；表现层**厂商条件分支清零**，跨模块**零直接引用**。
2. **契约先行**界定硬件无关能力边界：**17 个纯虚方法**覆盖**设备全生命周期、参数读写、图像获取**三域；**统一门面**收口多机映射与生命周期托管，上层仅依赖抽象；新品牌接入由**侵入式改造**降级为**增量式扩展**，改动面收敛 **95%**。
3. **10 种设计模式**体系化治理变化点：**创建解耦、入口收敛、异构适配、事件分发、算法可替换、流程固化、对象复制、全局资源治理、数据视图分离、高吞吐削峰**各归其位，选型以**变化点隔离**为唯一判据，杜绝模式堆砌。
4. **参数能力由代码资产转为配置资产**：**7 种**参数类型 × **5** 业务分组 × **37 项** Schema 建模，**配置与渲染引擎彻底分离**，视图**运行时动态装配**；新增型号**不编译、不发版**，周期由**人天级压缩至分钟级**，上线效率提升 **80%**，研发与技术支持实现人力解耦。
5. **声明式构建治理**替代手写工程黑盒：源码清单、依赖声明、资源打包、交付路径**全部代码化**，元对象与资源编译**全自动托管**；**3 个缓存变量**覆盖全环境差异，**官方包优先 + 手动兜底**双路径依赖探测，调试/发布构件自动二选；外部 SDK 缺失时**降级仿真可继续构建**，**单可执行文件零依赖交付**，部署成本下降 **90%**。
6. **界面即代码**替代可视化拖拽：全仓**零二进制窗体**，布局骨架、弹性策略、主题钩子**全量代码显式声明**；根治**生成代码不可读、不可评审、合并即冲突**三宗罪；参数区仅保留空壳视图，**6 类编辑策略**按类型运行时挂载，界面层对参数规模**完全无感**，大屏缩放与多机切换**无需重构**。
7. **多环境自适应兼容矩阵**：OpenCV 多部署形态、硬件 SDK 缺失降级、操作系统差异**三维覆盖**；资源内聚打包，调试与发布构件统一落盘，交付物**单一、可复现、可搬运**。
8. **虚拟设备抽象**消除硬件依赖瓶颈：同契约仿真实现**全链路替代**，开发、调试、演示、压测、持续集成**全程无需真机**，**硬件采购成本归零**，周期不可控风险清零。
9. 自研**高吞吐图像缓冲层**：空闲/工作**双队列复用 + 条件变量同步**，**保新弃旧**保障预览实时性，**稳态零动态分配**承载满帧压力；采集回调、缓冲队列、独立采集线程、界面渲染**四级异步隔离**，持续满帧下界面**零阻塞、零累积延迟**。
10. **发布-订阅总线**消除面板网状耦合：交叉联动收敛为 **6 类语义事件**定向投递，模块间**零直接引用**，新增面板与事件类型**不触动既有业务**；配套 **16 类故障语义**统一错误模型，异常收口至**状态栏 + 模态两级触达**。
